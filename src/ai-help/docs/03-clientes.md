# Gestión de clientes

## Crear un cliente

1. Ingresá al módulo "Clientes".
2. Presioná el botón "Nuevo cliente".
3. Completá los datos:
   - Nombre
   - Teléfono (opcional)
   - Dirección (opcional)
4. Presioná "Guardar".

## Editar un cliente

1. Ingresá a "Clientes".
2. Buscá el cliente en la lista.
3. Presioná "Editar".
4. Modificá los datos.
5. Presioná "Guardar".

## Buscar un cliente

1. Ingresá a "Clientes".
2. Usá el buscador por nombre.
3. Seleccioná el cliente.

## Para qué sirve un cliente

El cliente se usa para:
- registrar ventas
- llevar historial de compras

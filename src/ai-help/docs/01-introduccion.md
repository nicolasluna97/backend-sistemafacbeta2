# Introducción al sistema

Este sistema permite gestionar ventas, clientes, productos y stock en tiempo real.

Está pensado para vendedores que trabajan en la calle, por ejemplo:
- visitando clientes
- vendiendo productos directamente
- registrando ventas desde el celular

## ¿Qué podés hacer con el sistema?

- Crear y gestionar clientes
- Crear productos con distintos precios
- Registrar ventas en el momento
- Consultar stock disponible
- Ver movimientos de stock
- Analizar ventas realizadas

## Conceptos importantes

### Cliente
Es la persona o negocio al que le vendés productos.

### Producto
Es el artículo que vendés. Puede tener:
- diferentes tamaños
- diferentes precios

### Stock
Es la cantidad disponible de cada producto.

### Venta
Es una operación donde un cliente compra uno o más productos.

### Movimiento de stock
Es cualquier cambio en el stock, por ejemplo:
- una venta (reduce stock)
- una carga de stock (aumenta stock)

## Cómo usar el sistema

El flujo típico es:

1. Crear productos
2. Cargar stock
3. Crear clientes
4. Registrar ventas
5. Consultar movimientos

Este flujo se repite todos los días.

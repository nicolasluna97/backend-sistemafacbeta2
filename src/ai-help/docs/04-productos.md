# Gestión de productos

## Crear un producto

1. Ingresá al módulo "Productos".
2. Presioná "Nuevo producto".
3. Completá los datos:
   - Nombre del producto
   - Tipo o categoría
4. Presioná "Guardar".

## Configurar precios

Un producto puede tener diferentes precios.

Ejemplo:
- Precio para cliente A
- Precio para cliente B
- Precio por cantidad

## Editar un producto

1. Ingresá a "Productos".
2. Seleccioná el producto.
3. Presioná "Editar".
4. Modificá los datos.
5. Guardá los cambios.

## Buscar un producto

1. Ingresá a "Productos".
2. Usá el buscador por nombre.
3. Seleccioná el producto.

## Importante

- Un producto no tiene stock hasta que se carga.
- El stock se maneja por separado.

# Registro de ventas

## Crear una venta

1. Ingresá al módulo "Ventas".
2. Presioná "Nueva venta".
3. Seleccioná el cliente.
4. Agregá productos:
   - buscá el producto
   - seleccioná cantidad
5. Verificá el precio aplicado.
6. Confirmá la venta.

## Qué pasa al guardar la venta

- El stock se descuenta automáticamente.
- La venta queda registrada en el sistema.
- Se genera un movimiento de stock.

## Ver ventas realizadas

1. Ingresá a "Ventas".
2. Revisá la lista de ventas.

## Errores comunes

### No hay stock suficiente
- Reducí la cantidad
- o cargá más stock

### Precio incorrecto
- verificá la configuración del producto

# Cómo iniciar sesión

## Ingresar al sistema

1. Abrí la aplicación desde tu celular o computadora.
2. Ingresá tu email.
3. Ingresá tu contraseña.
4. Presioná el botón "Iniciar sesión".

## Problemas comunes

### No puedo iniciar sesión
- Verificá que el email esté bien escrito.
- Verificá que la contraseña sea correcta.

### Olvidé mi contraseña
- Usá la opción "Recuperar contraseña" si está disponible.

## Seguridad

- Cada usuario solo puede ver su propia información.
- Los datos de otros usuarios no son visibles.
